Several existing palliative care applications aim to help patients, families, and caregivers manage health conditions and end-of-life care. Developers typically incorporate the following tracking mechanisms:

|**App Name**|**Tracking Features Used**|
|---|---|
|**CareZone**|Medication tracking, task scheduling, symptom journaling, health record uploads|
|**PalliaCare India**|Volunteer coordination, help requests from families, pain level reporting, scheduling|
|**Hospice UK App**|Appointment tracking, patient status updates, support requests, digital visit checklists|

**Tracking Techniques Used by Developers:**

- **Forms**: Used to log symptoms, pain levels, or medication.
    
- **Reminders**: Timely push notifications for medicine or appointments.
    
- **Dashboards**: Simple overviews of patient status or volunteer tasks.
    
- **Manual Data Entry**: Caregivers or users enter health-related data daily.
    
- **Limited Real-Time Communication**: Usually through basic request forms, not chat or video.
